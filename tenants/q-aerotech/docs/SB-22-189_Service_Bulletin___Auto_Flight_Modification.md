# Service Bulletin — Auto Flight Modification

## Planning Information

This service bulletin introduces a modification to the Auto Flight system (ATA Chapter 22)
to address an out-of-tolerance actuator response time.

Compliance is recommended at 750 flight hours. Where an airworthiness directive mandates
this bulletin, the directive compliance time takes precedence.

Embodiment on aircraft QA-321N is planned during the next scheduled input and is managed
through engineering order EO-2026-0479. Where mandated, see ADCR-2024-0274.
