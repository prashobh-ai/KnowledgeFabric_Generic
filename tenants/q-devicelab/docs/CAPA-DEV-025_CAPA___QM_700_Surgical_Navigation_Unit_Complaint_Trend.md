# CAPA — QM-700 Surgical Navigation Unit Complaint Trend

**Document number:** CAPA-DEV-025  
**Document type:** CAPA Record

## Root Cause and Action

CAPA raised on complaint CMP-2025-05019 and a trend of reports of an error code presented
during start-up for the QM-700 Surgical Navigation Unit (cleared under K241822).

Root cause: the instructions for use did not state the limitation concerning use of a
consumable beyond its expiry prominently enough at the point of use.

Corrective action: revise the instructions for use and issue a customer notification.
Preventive action: add the limitation to the design review checklist.

Effectiveness verified through complaint rate monitoring.
