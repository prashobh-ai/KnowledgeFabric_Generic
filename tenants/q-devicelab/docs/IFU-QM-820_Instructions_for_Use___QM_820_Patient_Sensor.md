## Intended Use

The QM-820 Patient Sensor is intended for continuous monitoring of the physiological
parameter in acute settings. It is for use by trained healthcare professionals in the
settings described in this document.

This device was cleared under K241959. Use outside the stated intended use has not been
evaluated.

Manufactured by Q-DeviceLab.

## Warnings and Limitations

Do not use the device if an out-of-range ambient temperature is present or suspected.

Results may be affected by sample handling outside the stated conditions. Where this is
suspected, confirm by an alternative method before acting on the result.

Report any a result inconsistent with the clinical picture to Q-DeviceLab and, where
applicable, to the competent authority under 21 CFR 820.30.
