# CAPA — QM-960 Sterilisation Indicator Complaint Trend

**Document number:** CAPA-DEV-026  
**Document type:** CAPA Record  
**Owner:** Amara Delacroix (Manufacturing Quality Engineer, STF-3055)  
**Approved by:** Pieter Thornbury (Design Assurance Engineer, STF-8959)  
**Revision:** A  
**Effective:** 2024-07-07  

## Root Cause and Action

CAPA raised on complaint CMP-2025-05019 and a trend of reports of an error code presented
during start-up for the QM-960 Sterilisation Indicator (cleared under K242233).

Root cause: the instructions for use did not state the limitation concerning operation
outside the specified temperature range prominently enough at the point of use.

Corrective action: revise the instructions for use and issue a customer notification.
Preventive action: add the limitation to the design review checklist.

Effectiveness verified through complaint rate monitoring.
