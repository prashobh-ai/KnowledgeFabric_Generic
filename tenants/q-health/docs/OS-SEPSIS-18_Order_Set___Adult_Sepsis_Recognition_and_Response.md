## Contents and Deployment

Order set supporting the Adult Sepsis Recognition and Response pathway (CP-SEPSIS-01),
deployed in the electronic health record.

This set implements pathway CP-SEPSIS-01 under clinical policy CP-POL-300, supported by
decision rule CDS-029. It is presented to the ordering clinician when an unexplained
reduction in urine output over the preceding interval. Default selections reflect the
pathway; each may be deselected with a documented reason.

Contents include the initial assessment bundle, the associated laboratory requests, and the
escalation task routed to the responsible clinician at each documented reassessment.

Changes to this order set require approval by the Medical Staff Committee Chair and are
validated in the non-production environment before release.
