## Contents and Deployment

Order set supporting the Heart Failure Admission and Transition pathway (CP-CHF-04),
deployed in the pharmacy verification queue.

This set implements pathway CP-CHF-04 under clinical policy CP-POL-307, supported by
decision rule CDS-034. It is presented to the ordering clinician when a medication
reconciliation discrepancy identified at admission. Default selections reflect the pathway;
each may be deselected with a documented reason.

Contents include the initial assessment bundle, the associated laboratory requests, and the
escalation task routed to the responsible clinician within 60 minutes of recognition.

Changes to this order set require approval by the Pharmacy and Therapeutics Chair and are
validated in the non-production environment before release.
