# SOP — Heart Failure Admission and Transition Assessment

**Document number:** SOP-CLIN-283

**Approved by:** Clara Mwangi (Clinical Governance Lead, STF-9797)  
**Revision:** F  
**Effective:** 2026-06-06  

## Procedure

1. Confirm the patient meets the entry criteria for CP-CHF-04.
2. Record the assessment in the clinical decision support engine using the structured
template.
3. Where a serum lactate result returned above the reference range, refer to the specialist
team using the standard referral pathway.
4. Repeat the assessment at each documented reassessment until the criteria are no longer
met.
5. Document the outcome, including any deviation and its rationale.
