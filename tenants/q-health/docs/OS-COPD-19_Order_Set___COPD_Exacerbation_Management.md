## Contents and Deployment

Order set supporting the COPD Exacerbation Management pathway (CP-COPD-03), deployed in the
care management registry.

This set implements pathway CP-COPD-03 under clinical policy CP-POL-321, supported by
decision rule CDS-030. It is presented to the ordering clinician when an unexplained
reduction in urine output over the preceding interval. Default selections reflect the
pathway; each may be deselected with a documented reason.

Contents include the initial assessment bundle, the associated laboratory requests, and the
escalation task routed to the responsible clinician before the next scheduled medication
round.

Changes to this order set require approval by the Infection Prevention Lead and are
validated in the non-production environment before release.
