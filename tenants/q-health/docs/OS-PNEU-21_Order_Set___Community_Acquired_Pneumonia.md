## Contents and Deployment

Order set supporting the Community Acquired Pneumonia pathway (CP-PNEU-01), deployed in the
pharmacy verification queue.

This set implements pathway CP-PNEU-01 under clinical policy CP-POL-363, supported by
decision rule CDS-032. It is presented to the ordering clinician when a documented early
warning score above the escalation threshold. Default selections reflect the pathway; each
may be deselected with a documented reason.

Contents include the initial assessment bundle, the associated laboratory requests, and the
escalation task routed to the responsible clinician within 24 hours of admission.

Changes to this order set require approval by the Health Information Management Director and
are validated in the non-production environment before release.
