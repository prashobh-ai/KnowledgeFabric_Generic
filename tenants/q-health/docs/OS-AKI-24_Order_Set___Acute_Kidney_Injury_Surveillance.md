## Contents and Deployment

Order set supporting the Acute Kidney Injury Surveillance pathway (CP-AKI-01), deployed in
the pharmacy verification queue.

This set implements pathway CP-AKI-01 under clinical policy CP-POL-328, supported by
decision rule CDS-029. It is presented to the ordering clinician when a documented early
warning score above the escalation threshold. Default selections reflect the pathway; each
may be deselected with a documented reason.

Contents include the initial assessment bundle, the associated laboratory requests, and the
escalation task routed to the responsible clinician before the next scheduled medication
round.

Changes to this order set require approval by the Infection Prevention Lead and are
validated in the non-production environment before release.
