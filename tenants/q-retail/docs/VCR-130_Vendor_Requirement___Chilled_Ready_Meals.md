# Vendor Requirement — Chilled Ready Meals

**Document number:** VCR-130  
**Document type:** Vendor Compliance Requirement  
**Owner:** Amara Ferrers (Category Buyer, STF-3887)  
**Approved by:** Marcus Eriksen (Store Operations Manager, STF-9545)  
**Revision:** C  
**Effective:** 2026-09-09  

## Requirement

Vendors supplying Chilled Ready Meals to Q-Retail, including vendor VEN-2000, must comply
with the requirements in this document.

Every article must carry the age grading and associated safety warnings. Evidence must be
available for inspection within five working days.

Non-compliance may result in the affected article being blocked at goods receipt and a
chargeback applied.

## Traceability

Each despatch must carry the article identifier and the location identifier so that a unit
can be traced from source to shelf.

Data is exchanged through the traceability event repository. Where an unapproved change to
the component specification, the despatch is held pending correction.
