## Standard

This standard defines the documentation Q-Quality produces for a test engagement, aligned to
ISO/IEC/IEEE 29119-1 — concepts and definitions for software testing.

Each engagement produces a strategy, a plan per suite, specifications for each case, and a
summary report. Every case traces to a requirement such as REQ-1148.

Documentation is held in the automation execution grid and is auditable for the retention
period.
